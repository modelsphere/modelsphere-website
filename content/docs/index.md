ModelSphere Console 是推理平台的统一入口：在这里部署模型、试用模型、发放 API 密钥，程序再用密钥通过 OpenAI 兼容接口调用模型。

![ModelSphere 标识](./images/modelsphere-logo.png)

## 阅读顺序

| 章节 | 内容 |
| --- | --- |
| [快速开始](quickstart.md) | 登录、界面和菜单，跑通一次完整流程 |
| [部署模型](deploy.md) | 在模型库选模型，预览计划并确认部署 |
| [Playground](playground.md) | 在浏览器里和已部署的模型对话 |
| [调用 API](api.md) | 创建 API 密钥，通过 OpenAI 兼容接口调用模型 |
| [访问控制](access-control.md) | 用户、角色和登录历史 |
| [常见问题](faq.md) | 常见提示和处理方式 |

## 关于这份文档

这份文档随 Console 一起发布。实际看到的菜单和操作按钮取决于集群配置和账号权限，如果文档里提到的功能在当前环境没有出现，可以对照[常见问题](faq.md)里的提示排查。
