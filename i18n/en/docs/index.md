ModelSphere Console is the single entry point of the inference platform: deploy models, try them out and issue API keys here; programs then call models through the OpenAI-compatible API with those keys.

![ModelSphere logo](./images/modelsphere-logo.png)

## About this guide

This guide ships with the Console. The menus and actions you see depend on the cluster configuration and your account permissions; if a feature mentioned here is missing in your environment, check the matching entry in the [FAQ](faq.md).
