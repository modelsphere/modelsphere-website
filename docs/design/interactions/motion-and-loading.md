本模块集中维护门户各内容块的动效、滚动加载、设备降级、实施记录和验收证据。D01–D14 定义具体动作，L01–L06 定义资源加载，M01–M11 将两者映射到页面。动效用于说明可操作性、响应和阅读顺序，正文与数据始终稳定。

页面结构仅采用项目 3601238558355976464 顶部“首页-更新”“模型目录”“博客洞见-更新”三张；下方深色稿仅参考颜色，不恢复旧区块。Header 与已实现文档 Footer 保留组件契约中的既定例外；未覆盖页面继续遵守功能契约，视觉待补充，不以旧稿补足。本模块的动效参数是工程补充，设计中没有的控件或区块不因编号存在而新增。

## 4 播放打断与降级

1. 初始 HTML 和无脚本样式都是完整可见状态，不设 CSS 初始隐藏。首页 D01 与三个机制区 D03 对每个 `data-home-pair` 直接子块单独判定：该子块起点在初始化时尚未进入视口高度 85% 区域，才注册等待；已在主要阅读区域的不补播，不因父组或上一卡可见就消费后续卡。其他 D02/D03/D08 只增强初始化后仍在屏外的非关键区域，可见区域不补播；D13 仅在首次前台判定时文字组仍在 hero 视口内启动。D14 初始和屏外目标共用同一个观察器，均须起点进入视口高度 92% 的区域才由观察回调播放；初始仅露在底部 8% 时继续等待。只有脚本及观察器就绪后，才为尚未到触发线的并排及堆叠子块设置 `data-home-pending`、opacity=0；入场时移除等待标记并滑入。后台暂停时保留未播模块的空白状态；断点变化后重新观察未播模块。已播动画、焦点、锚点、减少动效和卸载清除相应等待标记。
2. 首页 D01 与三个机制区 D03 在每个直接子块自己的起点到达视口高度 85% 时触发一次；并排与堆叠都使用该门槛，同一视觉行同步（包括垂直居中的两侧），下一排或下一卡不提前播放。其余目标在起点进入视口高度 92% 区域时触发。观察起点而非要求整块达到某个可见比例，超长区块也能正常显示。动画完成后取消观察；入场位移跨回触发线时继续播放，只有实际离开视口才消费并结束。
3. 每个目标最多一个入场层级；D13 与 D14 独立播放，hero 父容器不动画。同一视口最多一个自动流程强调序列，优先 DOM 中先出现者，其他流程静态显示，不建立等待队列。用户主动切换的 D05 不受自动序列排队控制。
4. 键盘焦点进入、锚点直达、查找定位时立即结束目标的入场并显示最终状态；首页 D01/D03 的焦点或锚点进入时消费同一 `data-home-pair` 组的全部目标，避免后续阅读跳动。D14 在焦点或锚点进入 hero 时即取消揭示，避免裁切阅读目标。焦点指示不能随透明度变弱。浏览器历史恢复不触发新序列。
5. `prefers-reduced-motion: reduce` 下过渡、交错、流程强调和 smooth 全部关闭；状态切换即时完成。偏好在页面打开期间改变时立即取消进行中的动画；改回普通模式不补播。
6. 初始页面在后台时延迟到首次可见再按当前几何与 hash 初始化。D13 仅在该次首次前台判定符合条件时可播；一旦播放、取消或判为静态便消费，不在后台返回或跨断点后补播。进入后台或跨断点时结束并消费已开始的动画，保留从未播放的待观察目标并断开观察器；首页 D01/D03 以每个子块分别保留未播状态，不因同组上一卡已播放而消费下一卡。恢复时按该子块当前几何与对应触发线重新注册仍未到阅读区域的目标，不补播已在主要阅读区域或上方的内容。区块离开视口时结束其进行中动画；减少动效、历史恢复与组件卸载保持最终静态状态，不恢复播放；均不留下半透明或位移残留。
7. 不依赖动画完成事件提交查询、复制成功、开关导航或变更焦点；业务状态先确定，动画随状态表现。旧异步结果和已取消动画的回调不得覆盖新状态。
8. 动效实现不支持、初始化失败或相关资源未加载时显示静态最终状态；清除监听与计时器，不持续使用 `will-change` 或空转的逐帧回调。

## 5 异常反馈

| 异常 | 呈现 |
| --- | --- |
| 正常筛选零结果 | 空态和清除筛选入口，不展示“加载失败” |
| 图片加载失败 | 保留比例，显示简短替代说明；关键信息由附近文字承担 |
| 图示加载失败 | 保留标题与文字流程，显示图示不可用提示 |
| 字体加载失败 | 使用后备字体，正文保持可见 |
| 客户端交互初始化失败 | 保留可阅读内容与原生链接，显示筛选暂不可用提示；未初始化控件保持禁用 |
| 静态数据加载失败 | 保留已有内容、版本和重试提示；不把旧内容显示为刚更新 |

静态内容、文章、代码和导航必须可在 JavaScript 不可用时阅读。首期模型与博客的筛选和分页可依赖 JavaScript；禁用脚本时展示完整博客摘要和标明版本的 Catalog 构建基线目录。实时模型/配方详情提示需要 JavaScript；不留下看似可用却无效的控件。无筛选博客列表的推荐排除规则仍保持一致，推荐区补足该文章。
