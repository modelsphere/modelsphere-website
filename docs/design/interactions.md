## 2 状态模型与职责

页面维护以下状态：

| 状态 | 内容 | 存放与恢复 |
| --- | --- | --- |
| 已提交查询 | 搜索词、筛选值、视图、排序、页码、测评及配方版本 | URL 为唯一可分享来源 |
| 输入草稿 | 搜索框正在编辑的文字 | 组件状态；刷新或历史导航时用 URL 中的 q 覆盖 |
| 临时交互 | 菜单展开、复制反馈、当前标签 | 页面内存；不写入 URL 或本地持久存储 |
| 主题偏好 | system / light / dark 与解析后的实际主题 | Docusaurus 统一管理偏好；跨页面持久化，不写查询参数 |

首期不使用 localStorage 保存筛选或搜索历史。博客和文档使用同一网站发布产物；Catalog 首期使用公开数据源及其可追溯提交。浏览器不读取草稿、审核元数据或预览 fixture。

提交处理顺序：读取动作 → 规范化查询并更新 URL → 本地计算或请求对应版本的数据 → 计算分页边界 → 必要时规范化页码 → 渲染与反馈。不能先截取分页再筛选；异步计算期间保留已有结果并标明加载，只有当前查询响应可以更新视图。

对本地同步计算不显示加载动画。请求 Catalog 数据或加载本站数据文件时提供真实加载与失败反馈；只有当前查询对应的响应可以更新视图，旧响应不得覆盖新状态。按各来源携带版本标识，不能混用目录、详情和报告版本；固定版本失效时明确提示，不静默切到最新。

### 2.1 全站主题切换

- 首访默认“跟随系统”，实际主题根据系统偏好解析。点击太阳／月亮按钮后显式 light/dark 偏好优先，刷新和跨页保持；当前界面不提供第三个模式入口。
- 仅 system 模式响应运行中的系统变化；手动模式不被系统变化覆盖。偏好使用 Docusaurus 主题 provider 和其公开能力持久化，不额外实现独立 localStorage 状态。存储不可用时本次会话仍可切换，刷新回到系统偏好，不抛错阻断页面。
- Header 右侧常驻有可访问名称的太阳／月亮图标按钮；窄屏无需展开导航即可切换。首访 system 与手动 light/dark 的内部偏好仍分别表示，不能将首次解析结果误存为手动覆盖。
- 首次绘制前解析有效主题并设置根节点 data-theme 和 color-scheme，避免先白后黑；SSR 和 hydration 使用相同页面结构，不能通过客户端重建页面修正配色。无脚本时隐藏无效主题控件，以 CSS 系统偏好回退；不能读取已存手动偏好，不承诺该偏好在无脚本下恢复。
- 切换立即生效，无整页淡入、翻转或 View Transition；不改 URL、页面历史、输入草稿、筛选、已选版本、Tab、弹层与焦点，不重取业务数据。正文行长、图片尺寸、滚动位置不变。
- Logo、图表、代码高亮、搜索、表格、弹层、loading/empty/error、404 及标准文档全部覆盖；主题色不反转图片，视觉值以基础规范为准。运行中切换与减少动效均按 D12 验收。

## 3 搜索与筛选

搜索框带可见标签和“搜索”按钮，按钮复用 Button。Enter 与按钮执行同一提交；输入法组合输入期间 Enter 仅确认候选文字，不提交查询。

| 用户动作 | 查询变化 | 输入与结果行为 |
| --- | --- | --- |
| 编辑搜索文字 | 不修改 URL | 只修改输入草稿，不改变当前列表 |
| 提交搜索 | q 取输入草稿，page 重置为 1 | 保留其他筛选与 benchmark；焦点留在触发控件 |
| 选择筛选项 | 提交新筛选，同时提交当前搜索草稿，page 重置为 1 | 一次完成，避免搜索框文字与结果口径不同 |
| 点击搜索框清空按钮 | 清空草稿及 q，page 重置为 1 | 保留其他筛选和 benchmark；焦点返回搜索框 |
| 点击“清除筛选” | 清空 q 及所有目录筛选或博客 category/tag，page 重置为 1 | models 保留 benchmark；焦点移到搜索框，避免清除按钮消失后失焦 |
| 翻页 | 修改 page | 使用已提交查询；未提交的搜索草稿恢复为已提交 q |
| 切换视图、布局或排序 | 更新 view/layout/sort；视图或排序变化重置 page | 保留可共用筛选，查询与显示一致 |
| 选择配方版本 | 更新配方页 version | 保留模型与配方身份，加载对应历史并显示实际版本 |
| 切换测评 | 仅修改 benchmark | 不修改目录筛选、page 或搜索草稿 |

- 搜索按用户可见字符处理，先去除首尾空格，再截取到 100 字；不把组合字符或表情拆开。
- 超长输入保留到提交时统一规范化，并提示“搜索词最多保留 100 个字符”；不能仅依赖按编码单元计数的 maxlength。
- 按页面契约使用不区分大小写的连续文本匹配；主站不增加拼音、分词、模糊搜索或正则；Docusaurus 文档全文搜索按独立索引实现，不受此字段搜索限制。
- Catalog q 覆盖模型名称、简介、稳定标识及关联配方名称、镜像和硬件名称；仅使用来源实际提供的字段。博客 q 覆盖标题、摘要、作者、技术关键词、标签显示名和 PR 编号；PR 支持纯数字、`#数字`、`owner/repo#数字` 的已登记形式，不推测不存在的记录。
- 筛选选项从全部已发布集合生成，不随着其他筛选消失；否则无法稳定重放已分享的筛选条件。
- Catalog 默认 `view=recipes`，保留 `models` 切换与拓扑筛选；硬件 chip 使用原生 checkbox 多选语义，点击切换单项，Space 可操作，选中状态与可读名称一致。“全部”表示没有 hardware 条件，不与具体硬件同时选中；视觉不使用互斥单选语义。
- Catalog 默认 `sort=improvement-desc`，本期排序仅比较明确标注的源记录最佳负载增幅，保留负载、测量版本和报告，不表示同条件或跨模型统一性能排名。无值置后，同值按稳定 id。模型视图不自动挑最大提升作为代表。
- 排序控件或说明明确“各自相对基线的吞吐提升”，结果不是跨模型绝对性能排名；每条记录保留自身条件和来源。切换排序不改变测评选择，不重新计算或生成宣传结论，口径遵循内容与证据规范。
- 博客 category/tag 各单选，q/category/tag 之间为 AND。分类使用可访问的当前项标记；热门标签使用可切换按钮及 aria-pressed，点击已选标签清除 tag；不使用切换内容面板的 TabGroup 语义。标签来自真实字典，按全部已发布文章引用数降序、同值 id 升序取前 10 项，推荐文章只计一次；不随当前筛选集合改变热度或选项。
- 没有内容的目录不展示不可用的搜索和筛选控件；有内容但筛选无结果时保留控件和条件。
- 结果区通过礼貌播报提示“找到 N 条结果，第 X / Y 页”；零结果显示“未找到匹配内容”，不播报“第 1 / 0 页”。

可选 `/` 快捷键只在当前页面存在可用搜索框时聚焦，不自动提交；忽略 Ctrl/Meta/Alt、输入法组合、输入/文本域/select/contenteditable 内事件及已打开模态层。仅真正处理事件后阻止默认行为，不覆盖浏览器或编辑器快捷键。

## 4 URL 与浏览器历史

| 页面 | 已知查询参数顺序 |
| --- | --- |
| `/models` | q、family、engine、tag、hardware（多值）、topology、view、layout、sort、page、benchmark、dataVersion |
| `/models/detail` | modelId、dataVersion |
| `/models/recipe` | modelId、recipeId、version、benchmark、dataVersion |
| `/blog` | q、category、tag、page |

详情页 `modelId`、`recipeId` 是身份参数，缺失或非法时显示参数错误，不按筛选默认值忽略。版本失效与来源异常分别提示；详情固定路径 HTTP 200 的限制见页面契约。

序列化规则：

1. 使用标准 URL 查询参数编码；空值、page=1 以及 view/layout/sort 的默认值省略，禁止手工拼接未经编码的搜索词。
2. 单值参数重复时取首值；hardware 收集全部合法值、去重并按稳定 id 排序序列化；未知参数移除。fragment 单独处理，不作为筛选条件。
3. page 只接受十进制正整数；超出可安全表示范围按非法值处理。非正整数归一为 1，超出末页归一到末页，零结果归一为 1。
4. 家族、引擎、标签（包括博客 tag）、拓扑和分类非法时忽略该项并提示；hardware 仅移除非法值；view/layout/sort 非法时回到页面契约默认值 recipes/cards/improvement-desc。报告的 modelId/recipeId、配方 version 或 dataVersion 显式无效时保留请求值并展示错误，不能换成其他记录或最新版本。
5. 配方详情的性能 Tab 必须明确提供 modelId 和 recipeId；参数缺失时提示不完整，不自动选择默认报告。目录不再保存 benchmark 状态。
6. 页面显示与 URL 必须使用同一份规范化查询；不能显示已纠正结果却复制出原非法参数。

历史记录：

- 用户提交搜索、选择筛选、清除条件、翻页和切换测评使用新历史项；规范化后的 URL 未变化时不新增历史项。
- 首次加载纠正非法参数使用替换当前历史项；纠正提示在同次导航只显示一次。
- 后退或前进时从 URL 恢复状态，丢弃未提交搜索草稿；不反向新增历史项，也不自动触发新的滚动定位。
- 普通链接保留浏览器原生的新窗口、复制链接和修饰键行为；只增强当前窗口的正常导航。
- 首次直达含参数页面，不应先闪现默认列表再替换为查询结果；工程方案必须处理这一初始化条件。

同页目录操作保留原有 fragment；它不触发滚动。翻页后的滚动由第 6 节负责。“查看配方详情”进入 `/models/recipe?modelId={id}&recipeId={id}&dataVersion={commit}`；点击源记录增幅携带 `tab=performance`。详情默认部署配置，另有性能对照、版本历史 Tab；Tab 选择写入 URL，保留 version、dataVersion 与 returnTo，不重置焦点或滚动，不重载同一配方已加载的数据。左右键与 Home/End 移动焦点，Enter/Space 激活。旧 `/models/report`、目录 benchmark 和配方 `#benchmark` 链接替换当前历史项进入配方性能 Tab，返回目录时恢复 returnTo 中的查询并移除旧报告选择。

## 5 博客推荐与分页

q、category 和 tag 均为空时，所有页共用排除推荐文章后的列表集合；在此集合上排序、计数和分页。推荐区仅在第 1 页显示。存在任意搜索、分类或标签条件时，不显示推荐区，列表在全部已发布文章中筛选，允许推荐文章作为普通匹配结果出现。

明确边界：

- 未配置推荐文章时，不执行排除。
- 推荐 id 不存在或未发布属于内容校验错误，不在运行时换一篇。
- 只有一篇推荐文章且无其他文章时，第 1 页显示推荐区和“暂无其他文章”，不显示“尚无公开文章”。
- 页码归一化依据上述同一集合；不能用排除前总数生成页码。
- 页面始终保留屏幕阅读器可访问的博客 h1，不增加独立视觉 hero；推荐文章标题为 h2。微信/知乎侧栏只在有真实配置与有效目标时显示，缺失隐藏；二维码提供文字加入说明，侧栏不产生注册、登录、追踪或伪造统计交互。

审核示例：25 篇已发布文章中有 1 篇推荐文章，无筛选时列表总数为 24，分两页各 12 篇；推荐文章仅在第一页推荐区出现。两页列表 id 不重复，且并集等于除推荐文章外的全部 24 篇。

## 6 分页与测评选择

分页使用带真实 href 的原生链接，不创建仅能点击、无法复制的页码控件。当前页使用 aria-current；不存在上一页或下一页时显示不可交互文字，不用 `href="#"`。

桌面和平板显示首末页、当前页及前后各 1 页，间隔用非交互省略号；手机仅显示上一页、当前页 / 总页数、下一页。只有 1 页或零结果时不显示分页导航。

主动翻页后，将列表区标题滚动至 Header 偏移以下，并把焦点移到该标题；标题可程序化聚焦，但不进入常规 Tab 顺序。搜索与筛选则保留触发控件焦点，不强制滚动。

测评选择：

- 使用原生 FilterSelect，选中项显示模型与测试环境的可读名称，不只显示 id。
- 测评选择只更新详情和相应 URL 参数，不改变目录结果。
- 在测评区切换记录时保留选择框焦点，不自动跳回页首；卡片“查看测评”主动激活时先更新 URL/记录，再定位并聚焦测评标题。外部入口进入也定位标题；主题切换不触发定位。
- 选中记录无效时显示“该测评不存在或已撤下”，以及可用记录选择；不得悄悄替换为默认测评。
- 记录存在但关联配方不在当前筛选结果中时，在详情前显示说明；该状态不是错误，不清空测评结果。
- 全部测评为空时显示空态，不输出空表格或不能选择的下拉框。

## 7 导航与焦点

Header 各断点最小高度 64px；<1280px 使用可展开导航，≥1280px 展开全部主导航。文字放大时允许换行增长，不压缩字号或裁切入口。主题控件、品牌和当前导航均需适配。

| 场景 | 行为 |
| --- | --- |
| 打开移动导航 | 焦点保留菜单按钮，下一个 Tab 进入首个菜单链接；不锁定页面滚动，不建立模态焦点循环 |
| Escape 关闭菜单 | 焦点回到菜单按钮；关闭后菜单链接不再可聚焦 |
| 点击菜单内链接 | 关闭菜单，然后执行目标导航；新页面焦点规则优先，不再拉回菜单按钮 |
| 从窄屏进入桌面 | 清除折叠状态；若焦点原在将消失的菜单按钮，转到品牌链接；菜单链接本身保持可访问 |
| 从桌面进入窄屏 | 默认收起；若焦点位于即将隐藏的导航链接，转到菜单按钮 |
| 客户端跨页导航 | 更新文档标题，滚到页首并聚焦 h1；有 fragment 时改为目标标题 |
| 原生整页导航或浏览器历史恢复 | 尊重浏览器行为，不重复抢焦点或强制回页首 |
| “跳到主要内容” | 聚焦 main，使用临时程序化焦点目标，不增加常规 Tab 停靠点 |

锚点偏移为实际占据视口顶部的 Header 高度 +16px；Header 不吸顶时仅保留 16px。应随文字换行、字体加载和安全区变化更新实际高度，不写死 64px。标题在导航后必须可见；已撤下区块的旧 fragment 不导致页面 404，页面正常展示且不尝试循环定位。

不拦截浏览器缩放快捷键，不设置正数 tabindex，不用视觉顺序改变键盘阅读顺序。

### 7.1 聚焦与操作质感

| 对象 | 悬停与按下 | 键盘聚焦 |
| --- | --- | --- |
| 主次按钮、明确链接 | 颜色 150ms；按钮按下 80ms 回馈色变化，不整体缩放；箭头保持位置 | 立即显示既有 2px 轮廓与 2px 偏移，不淡入、不等待动画 |
| 单一目标的整卡链接 | 150ms 改变主题强调边框和轻阴影；不平移或缩放 | 使用同一强调色与阴影，保留焦点轮廓；键盘聚焦时卡片不位移 |
| 含多个链接的信息卡 | 只有实际链接响应；普通卡片不整体抬升 | 各链接独立聚焦，卡片本身不新增 Tab 停靠点 |
| 搜索框与原生选择框 | 边框与底色 150ms；标签始终可见 | 外框立即可辨；输入不触发导航，焦点不触发筛选提交 |
| 当前导航与当前标签 | 使用稳定的文字强调与底色，不加循环呼吸 | 当前项与焦点态同时可辨，不用选中底色代替焦点轮廓 |

悬停反馈仅在 `(hover: hover) and (pointer: fine)` 下启用；触屏提供按下反馈，所有说明和操作无需悬停即可获得。减少动效时保留颜色、阴影和轮廓的最终状态，取消位移与过渡。文字链接保持下划线等可辨线索；各主题使用基础规范对应焦点色，终端使用专用色。不得使用 `outline: none` 后遗漏替代轮廓。

### 7.2 滚动与阅读位置

| 场景 | 设计行为 |
| --- | --- |
| 手势、滚轮、触控板连续阅读 | 使用浏览器滚动；不拦截滚轮、不整屏吸附、不视差、不用平滑滚动库改写惯性 |
| 点击同页锚点 | 仅指针激活、目标距离不超过当前可视高度且未减少动效时使用原生 smooth；更远目标立即定位 |
| 键盘激活锚点、跳过导航、主动翻页 | 立即定位并按既有规则聚焦目标；不让焦点先落在屏外等待动画 |
| 跨页链接或首次带 fragment 访问 | 直接显示目标内容，保持第 7 节焦点职责；不从页首播放到页尾 |
| 前进、后退和浏览器恢复 | 保留原生滚动恢复；不重播入场，不用锚点高亮反复牵引阅读位置 |
| Header 随页面滚动 | 常规高度下吸顶，滚过顶部 16px 后在 150ms 内增强至既有导航边框与普通卡片阴影；不缩高、不隐藏、不动画模糊半径 |
| 到达主动点击的目标 | 目标标题立即可读；旁侧短标记使用 info 色提示 600ms 后消失，减少动效时不显示该装饰 |

近距离平滑滚动由浏览器决定时长，不承诺固定毫秒数；必须能被新的滚轮、触摸或键盘导航中断。不能保证可中断的环境回退到立即定位。链接保留真实 href 与 fragment；增强逻辑不得改变修饰键、新窗口或历史行为。必要的焦点设置使用防止额外滚动的方式，不再补发第二次定位。

首屏标题、按钮、正文和 LCP 候选图片直接显示。屏外区块的轻入场见第 10 节；进入阅读区后不再随滚动反复淡入淡出。保留页面及局部滚动条，不以 `overflow-x: hidden` 掩盖布局溢出。

### 7.3 展开与弹出反馈

主站场景包括移动导航展开、复制反馈、原生 select、硬件 checkbox 多选与 D07“完整测试条件”弹层。每种场景使用自己的语义，不统一包装成弹窗。

| 场景 | 打开与关闭 | 焦点、滚动和布局 |
| --- | --- | --- |
| 导航展开区 | 打开 200ms，内容 opacity 0→1、向下 4px 到原位；关闭 120ms 淡出，不做弹簧回弹 | 位于导航栏下方的文档流内，立即分配空间，不补间高度；遵守第 7 节非模态规则 |
| 复制成功或失败 | 按钮内图标与文字 150ms 更新；成功保持 2 秒，失败持续显示 | 预留反馈位置，文字不跳动；不新增全局 Toast，不移动焦点，不自动滚动 |
| 筛选原生 select | 使用设备原生展开和关闭，不定制选项弹层动画 | 保留原生键盘、触屏选择与关闭行为 |
| 测评“完整测试条件”弹层 | D07 提案：遮罩与面板只淡入 200ms、淡出 120ms，不缩放、不由卡片变形 | 独立模态语义，背景 inert、焦点循环、Escape 关闭与焦点恢复；导航展开仍为非模态 |
| 其他弹窗或抽屉 | 本稿未增加其他场景 | 须先补组件与页面契约，不自动把二维码、代码、文章或普通入口改成弹窗 |

导航关闭时先按关闭原因处理焦点，再立即将链接移出 Tab 顺序与可访问树；可保留 120ms 的非交互视觉退出，完成后隐藏布局。普通关闭若焦点仍在菜单内，回到菜单按钮；链接跳转按新页面规则处理。快速反复开关取消上一段动画，从当前视觉状态衔接，不能等待旧结束事件再次隐藏新菜单。减少动效或动画 API 不可用时立即切换，不依赖动画结束才更新语义状态。

菜单展开时 Header 整体进入普通文档流，允许页面自然滚动到全部链接；关闭后恢复原吸顶策略。页面不锁滚动、不加遮罩。失去焦点且焦点已到 Header 外部时可收起菜单，但不得把焦点拉回。

## 8 响应式布局

断点完全继承设计基础规范。屏宽和主题变化只更新呈现，不重置查询、已选测评、活动标签、代码内容或搜索草稿。

| 区域 | 手机 <768px | 平板 768–1279px | 桌面 ≥1280px |
| --- | --- | --- | --- |
| 栅格 / 页边距 / 列间距 | 4 列 / 16px / 16px | 8 列 / 24px / 20px | 12 列 / 32px / 24px |
| 首页四张能力卡 | 1 列 | 2 列 | 2 列 |
| 首页 QoS/SLO 机制卡 | 1 列 | 2 列；内容不足宽时纵排 | 2 列 |
| Catalog 卡片 | 1 列 | 2 列 | 最多 4 列 |
| 博客列表与渠道侧栏 | 列表单列，侧栏移至列表后 | 列表单列，侧栏移至列表后 | 列表占 8/12、侧栏占 4/12；无侧栏时列表使用可用宽度 |
| 社区资源卡 | 1 列 | 2 列 | 最多 3 列 |
| Catalog 汇总 | 1 列 | 2 列 | 最多 5 列；长标签可减列 |
| 搜索与筛选 | 搜索表单全宽，各筛选独占一行 | 搜索全宽，筛选两列换行 | 搜索全宽，筛选按可用宽度换行；硬件标签另行 |
| CTA 操作组 | 纵向排列，按钮全宽 | 横向排列，可换行 | 横向排列，可换行 |
| 门户页脚 | 四组导航单列，品牌在前 | 四组导航两列 | 品牌占两格、四组导航各一格；文档内容和紧凑横栏布局保留既定独立配置 |

其他布局规则：

- 首屏默认先标题与操作入口、后图示，不新增未在页面契约声明的侧栏。
- 卡片使用可缩小的栅格轨道，子项最小宽度为 0；长 URL、文件名和模型名可断行，不以省略号丢失关键信息。
- 图示保留可读字号；窄屏优先显示等价文字步骤。确实需保留宽拓扑时在图示容器内滚动，并保留文字摘要。
- 正文图片、Logo 和架构图按固有比例完整缩放；推荐封面 16:9、列表封面 3:2，仅在有审核过的裁剪预览时使用 object-cover，无审核预览则 object-contain。提前预留比例，避免加载后挤动焦点目标；封面悬停不放大。
- BenchmarkTable 和 CodeBlock 在自身区域横向滚动，不能撑宽整页；只有实际溢出时才额外提供可聚焦滚动区域，并给出可访问名称。
- 导航、筛选和内容不依赖固定页面高度；320px 视口与 200% 文字缩放时仍应能读取和操作全部内容，宽数据区允许局部滚动。

### 8.1 按页面重排，而非等比缩小

| 页面区域 | 手机 | 平板及桌面补充 |
| --- | --- | --- |
| 实际使用的 hero | h1 → 简介 → CTA → 图示；标题自然换行，按钮纵排；不设整屏固定高度 | 博客列表不增加视觉 hero；其他页面保持页面契约阅读顺序，不为留白撑至一屏高 |
| 首页 `comparison` | 四张能力卡完整纵排，标题 → 说明 → 能力面板 | 两列并排，DOM 顺序支持线性阅读，不增加四项 Tab |
| 首页 `fault-tolerance / qos-scaling / autotune-evolution` | 先说明、后图示；断流步骤和调优五步纵排，全部文字可读 | 机制图文可并列；调优闭环保留编号和等价文字，不能替代成一次请求五步图；动效不改变信息顺序 |
| 架构 `topology` | 五层纵排，层内节点换行，保留边界、名称和文字职责 | 采用 wide 容器；≥1280px 按 D05 选择层级联动图示；无法重排的复杂图局部滚动 |
| 架构各机制 | 先解释、再图示、后来源；条件区块缺失不留空隙 | 图文可并列；动效不改变内容顺序与信息完整性 |
| 模型 `catalog` | 搜索与每个筛选独占一行；验证状态和配方入口保持可见 | 卡片按 2/4 列；缩放时可因内容装不下而减少列数，禁止硬撑 |
| 模型 `benchmark` | 模型与条件 → 选择框 → 表格 → 来源；表格局部滚动，不删列或省略数值；完整条件可按 D07 打开 | 只在表格区域用 wide；caption、关键条件和来源保持常驻 |
| 文档侧栏 / 正文 / 目录 | Docusaurus 标准折叠导航与目录，正文单列；复制按钮位于代码工具栏 | 桌面使用标准侧栏、正文与标题目录；同站导航和主题，不复制营销 quickstart 稿 |
| 博客 `featured / posts / channels` 与正文 | 推荐图与文字纵排；封面按审核预览裁剪、无预览则完整显示；标签换行，渠道卡移至列表后；正文和长链接自然换行 | 列表保持纵向卡片与右侧条件性渠道卡；详情左目录/中正文/右资源，<1280px 合并为正文前目录、正文后资源；正文不超过 72ch/760px，代码和表格局部滚动 |
| 社区 `repositories / contribute / channels` | 按类别纵排；Logo 和二维码保持比例；二维码旁提供同设备可用的文字入口或加入说明 | 仓库和资源仍按既有 2/3 列；二维码不依赖悬停放大或弹出后才能使用 |
| 社区 `ecosystem` | 项目纵向网格与静态关系说明，按 D09；不建立横向图库 | 平板 2 列、桌面 3 列；不把目录或博客网格改成图库 |

上表的内容适配优先于理想列数：当文字放大或长内容导致卡片不可读时，先减少列数再增加高度。不能缩小全页、隐藏正文或删入口。宽拓扑的线性说明与原图来自同一内容；辅助图形不重复制造屏幕阅读器内容。

### 8.2 设备能力与极端尺寸

| 条件 | 具体规则 |
| --- | --- |
| 320–430px 窄屏 | 沿用 16px 页边距，320px 时内容宽 288px；卡片用 16px 内边距；搜索提交按钮不足一行时放到下一行 |
| 768/1024px 平板及分屏 | 以实际 CSS 视口计算布局，不按机型或设备像素；横竖切换只改布局，不清空输入和选择 |
| 1920/2560px 超宽屏 | default 最大 1280px，明确的 wide 最大 1440px；增加两侧留白，不扩大字号、卡片数量或正文行长 |
| 横屏、分屏或可视高度 ≤480px | Header 取消吸顶，菜单随文档流滚动；不使用 `100vh` 固定 hero；页面上每个操作仍可滚动到达 |
| 刘海、圆角屏与底部手势区 | 页面边缘按 `max(断点留白, env(safe-area-inset-*))` 处理；Header 顶部补安全区，内部卡片不重复加 |
| 触屏与混合输入设备 | 独立操作目标至少 44×44px，相邻独立目标至少 8px 间距；正文内文字链接保留自然行内排版；鼠标悬停不作为功能入口 |
| 软键盘出现 | 保留焦点与输入草稿，提交按钮可滚动到达；不强制回页首、不每次键盘高度变化重定位；输入与 select 文字至少 16px，不禁用缩放 |
| 200% 文字缩放 / 400% 页面缩放 | 不裁切、重叠或丢功能；1280px 页面放大 400% 时按约 320 CSS px 重排，不能以整页横向滚动代替 |
| 字体与文字间距替换 | 后备字体立即可用；行高 1.5 倍、段后距 2 倍字号、字距 .12em、词距 .16em 的用户覆盖仍不裁切 |
| 高对比度与强制颜色 | 使用系统可辨边框和焦点；状态有文字、当前项有语义，不只靠阴影、渐变或颜色区别 |
| JavaScript 或媒体能力不可用 | 静态内容先可见；菜单和原生链接有可用回退；动效不可用不阻止阅读、复制代码文本或访问完整博客摘要和标明版本的 Catalog 基线目录 |

布局宽度使用容器可用宽度，避免以 `100vw` 加内边距造成溢出。导航在窄屏顶部保留品牌与菜单按钮，“快速开始”放入展开区以保证 320px 可操作；页面 hero 内的主要 CTA 继续直接可见。禁用脚本时导航链接直接在文档流内展示，不留下打不开的菜单按钮。

### 8.3 资源、滚动区与低性能设备

- 按实际展示宽度输出响应式图片与 `sizes`，不能让手机默认下载桌面大图；封面预留 16:9/3:2 展示空间，裁剪仅使用审核预览，其他图片保留固有比例。首屏关键图片正常加载，屏外图片延迟加载；不等待动效才请求素材。
- 静态 SVG 或图片优先；首期不为装饰引入视频、Canvas 粒子、WebGL、Lottie 或额外动画库。已有矢量图可增加装饰层，不能把整张截图切成伪可交互区域。
- CodeBlock 与 BenchmarkTable 只在自身容器滚动；实际溢出时显示“可横向滚动查看”并提供可聚焦区域。焦点轮廓留出空间，触摸横向滚动不阻止页面纵向滚动。
- 代码保留空白与完整内容，不任意折断会影响理解的命令；复制按钮在横向滚动内容之外，长标题换行。表格不能为手机移除测试条件或结果列。
- 运行时不根据设备品牌、浏览器名称或网络猜测业务内容；无动效能力、减少动效、不可见页面时直接保留静态结果。若支持节省流量信号，省去非必要装饰素材，不移除正文图片或内容。
- 不在滚动每一帧读取布局或更新组件状态；使用一次性可见性观察。动画只作用于小范围 opacity/transform，颜色与轻阴影仅用于控件；不动画宽高、定位坐标、大面积阴影或模糊半径。

## 9 复制与标签切换

CodeBlock 状态机沿用组件契约：

| 当前状态与动作 | 下一状态 | 用户反馈 |
| --- | --- | --- |
| 默认，点击复制 | 复制中 | 保留按钮尺寸，阻止重复触发 |
| 复制成功 | 已复制 | 非打断式播报成功，2 秒后恢复默认 |
| 复制失败或 API 不可用 | 失败 | 显示“复制失败，请手动选择代码”，保留重试 |
| 失败后重试 | 复制中 | 重新执行一次复制 |
| 任意状态下代码内容改变或组件卸载 | 重置或清理 | 清理计时器，忽略旧内容对应的异步完成结果 |

复制只由用户动作触发，不读取剪贴板；不自动选择整页文字。代码本身始终允许手动选取，未知高亮语言回退为纯文本。

TabGroup 使用手动激活：左右键移动标签焦点，Home/End 到首尾，Enter/Space 激活；焦点移动本身不切换面板。点击标签同时聚焦并激活；活动标签在局部横向滚动区内可见，不能造成页面横向滚动。

非活动面板不进入可访问树和 Tab 顺序；切换标签不丢失尚未提交的输入。只有页面实际使用标签组件时才实现标签实例，不为了演示增加页面区块。

## 11 验收场景

以下是后续实现的行为断言，不表示当前已有可运行页面或测试：

1. 中文输入法确认候选不会提交；显式搜索提交后 q、输入框和结果一致。
2. 查询从第 2 页改为新条件时回到第 1 页；刷新和前进后退恢复 URL 对应结果。
3. 非法筛选、超长 q、重复参数、无效页码按规则纠正；无效 benchmark 不被静默替换。
4. 博客 25 篇含 1 篇推荐文章的场景，无筛选时两个列表页无重复无遗漏；q/category/tag 任一生效时隐藏推荐区且可在普通结果中找到匹配的推荐文章，刷新和历史恢复保留标签状态。
5. 修改模型筛选不改变当前测评；切换测评不改变目录页码。
6. 菜单开关、跨断点、锚点跳转和翻页后焦点均可见，且不会落在隐藏元素上。
7. 按第 11.2 节完成视口、输入方式与设备矩阵；不得仅凭桌面浏览器缩窗判定移动端通过。
8. 代码复制失败、图片失败、字体失败和减少动效模式均保留可用内容。
9. 禁用 JavaScript 时可阅读全部博客摘要和 Catalog 构建基线目录；实时模型/配方详情提示脚本要求，基线版本及筛选限制明确可见。
10. 首访跟随系统、太阳／月亮切换、刷新、跨页、存储失败与 system 下运行中的系统变化均正确；首次绘制无错误主题闪烁；主题切换不重置业务状态。
11. 动效、滚动加载与设备降级按[独立模块第 11 节](interactions/motion-and-loading.md#11-验收检查)逐项检查，并在模块第 10 节登记结果。
12. Catalog 默认 recipes/cards/improvement-desc；模型视图、拓扑与硬件多选可操作。增幅明确标注为源记录引用，无值置后；模型视图不取最大提升作为代表。
13. 推荐/列表封面分别预留 16:9/3:2；无审核裁剪预览时完整显示，正文及架构图不裁剪，悬停无图片放大。博客没有视觉 hero，隐藏 h1 与推荐 h2 层级正确；渠道缺少配置时不留空位。

### 11.1 Git 内容维护与发布反馈

首期没有网站编辑后台。作者在本地编辑器或 Git 平台修改 Markdown、元数据和图片，通过 PR 与 CI 查看预览和检查结果；实际权限遵循仓库及部署环境配置。

| 阶段 | 用户可核对的信息 |
| --- | --- |
| 分支编辑 | 修改文件和 commit；保存不改变线上版本 |
| PR 检查/预览 | 对应 SHA、检查结果、全站预览入口；失败提供实际原因 |
| 合并后候选 | 合并 SHA、文档源 commit、构建和镜像 digest；不能沿用不同 SHA 的旧结果 |
| 发布/失败 | 部署阶段、实际版本和可访问入口；失败保留旧站 |
| 撤回/恢复 | 对应 Git 变更与发布结果；检查全文、摘要、引用和资源 |

本地预览用于排版，正式候选使用网站模板。发布绑定已验证 digest；重试不能换入新的内容或依赖，旧任务不能覆盖新部署。状态显示由仓库与流水线提供，不在官网新增发布管理页面。

## 12 开发者文档交互

Docusaurus 提供标准侧栏、标题目录、代码复制与上一页/下一页；导航与正文无需等待装饰动画。Header 搜索通过点击或 `⌘K` / `Ctrl+K` 打开原生模态弹窗，桌面和手机均保留入口；焦点限制在弹窗内，Escape、关闭按钮或点击遮罩关闭并恢复焦点。输入即搜索，中文输入法组合期间不更新查询或触发 Enter 跳转。范围为全部／文档／博客，英文忽略大小写，空格分隔关键词采用 AND 匹配，输入最多 100 字符。标题命中优先，每页保留最相关小节，结果高亮标题、小节、摘要及标签，点击或方向键加 Enter 跳到实际页面／锚点。首批显示 20 条，可继续加载结果；切换主题和断点保留当前查询。

搜索只包含当前站已发布的文档和站内博客，排除站外文章、草稿及内部规范；索引随站点构建，首次打开时加载并在会话内缓存。加载超过 10 秒或格式无效显示失败和重试；无已发布内容与无匹配结果分别提示。无脚本禁用入口并提示，正文仍可读，代码与表格局部滚动。Header 查询不写入列表 URL，不改变博客列表既有搜索草稿与筛选状态。

文档与门户通过统一站点导航连接，链接保留原生 href；只显示实际存在的正文入口。文档源 commit 更新后经网站 PR 预览、合并并统一发布；网站回滚同时恢复博客和文档，不回滚实时 Catalog。索引失败保留文档正文并提供重试。
